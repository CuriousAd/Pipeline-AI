# Pipeline AI Integrations Assessment

This repository contains the backend and frontend for the Pipeline AI integrations assessment.

The completed HubSpot implementation in this repo supports:

- OAuth authorization
- OAuth callback and credential handoff
- Loading HubSpot `Contacts`, `Companies`, and `Deals`
- Displaying loaded items in the frontend with a small summary and preview

## Stack

- Frontend: React
- Backend: FastAPI
- Local state storage: Redis

## Project Structure

- `backend/` contains the FastAPI app and integration logic
- `frontend/` contains the React UI
- `compose.yaml` starts Redis locally
- `.env.example` shows the required environment variables

## Environment Setup

Create a root `.env` file at:

`C:\Users\Aditya\Downloads\Pipeline AI Assignment\.env`

Use this shape:

```env
HUBSPOT_CLIENT_ID=
HUBSPOT_CLIENT_SECRET=
HUBSPOT_REDIRECT_URI=http://localhost:8000/integrations/hubspot/oauth2callback

AIRTABLE_CLIENT_ID=
AIRTABLE_CLIENT_SECRET=
AIRTABLE_REDIRECT_URI=http://localhost:8000/integrations/airtable/oauth2callback

REDIS_HOST=localhost
REDIS_PORT=6379
FRONTEND_ORIGIN=http://localhost:3000
```

Important:

- The backend reads values from the real root `.env`, not `.env.example`
- If you change `.env`, fully restart the backend process

## HubSpot App Setup

For local testing, configure your HubSpot app with:

- Redirect URL: `http://localhost:8000/integrations/hubspot/oauth2callback`
- Required scopes:
  - `oauth`
  - `crm.objects.contacts.read`
  - `crm.objects.companies.read`
  - `crm.objects.deals.read`

## Local Run

### 1. Start Redis

From the repo root:

```powershell
docker compose up -d redis
```

### 2. Start the backend

From the repo root:

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload
```

You can verify the API is up at:

`http://localhost:8000/`

### 3. Start the frontend

From `frontend/`:

```powershell
npm install
npm run start
```

The app will open at:

`http://localhost:3000/`

## Frontend OAuth Test Flow

Use the app UI to start OAuth. Do not validate the final integration using HubSpot's raw `Test URL`, because the backend expects an OAuth `state` generated by the app's `/integrations/hubspot/authorize` route.

Test flow:

1. Open the frontend
2. Select `HubSpot`
3. Click `Connect to HubSpot`
4. Complete the OAuth popup
5. Click `Load Data`

Expected result:

- The frontend shows a loaded summary
- Items are grouped by type count in the summary
- The raw payload is shown below for inspection

Sparse accounts are supported, so empty results are valid.

## Useful Commands

Check whether HubSpot env values are visible to the backend:

```powershell
.\.venv\Scripts\python.exe -c "from backend.config import get_settings; s=get_settings(); print(bool(s.hubspot_client_id), bool(s.hubspot_client_secret), s.hubspot_redirect_uri)"
```
